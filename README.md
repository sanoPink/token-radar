Frank Signal is a token launch radar: it scores every rankable pre-token protocol by an implied value set by the market's own category multiples, ranks them on a board, and gives each protocol a seven-step farm plan.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
